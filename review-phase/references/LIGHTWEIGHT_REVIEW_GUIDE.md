# LIGHTWEIGHT_REVIEW_GUIDE.md

Lightweight review is not weaker review. It is narrower review.

Approve only when:

- the work stayed within one small/local task
- implementation matches the lightweight plan
- validation is enough for the stated scope
- no hidden PRD, Architecture, ADR, or Roadmap work was introduced

Route away from lightweight mode when:

- scope expanded
- behavior is ambiguous
- architecture changed
- durable decision is needed
- delivery sequencing is needed
- validation evidence is insufficient
